# P2N - Call of Duty Centralized Platform

![P2N Logo](https://www.psu.com/wp/wp-content/uploads/2021/11/Call-Of-Duty-Vanguard-Polina-Petrova.jpg)

**P2N** est une plateforme centralisée conçue pour simplifier l'accès aux ressources, installations et outils pour l'univers **Call of Duty**. Développé indépendamment par **Полина (H4)** et lié au projet **Jup9iw**.

## 🚀 Fonctionnalités

- **Catalogue de Jeux (Port)** : Accès direct aux builds et installations (MW4, MW3, MWII, Vanguard, etc.).
- **Outils & DLLs** : Ressources essentielles comme `version.dll`, `StartGame.bat` pour le bypass et l'optimisation.
- **Forum & News** : Actualités et rapports de bugs en temps réel (ex: Acces Violation COD VG).
- **HQ (Headquarters)** : Liens vers les projets partenaires (LUMEN, IW8-MOD, IW8X).
- **Base de DVARs** : Liste de commandes pour personnaliser votre expérience de jeu.

## 🛠️ Installation & Utilisation

Le site est statique et peut être hébergé sur n'importe quel service (GitHub Pages, Vercel, Netlify) ou ouvert localement.

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/votre-username/p2n-web.git
   ```
2. Ouvrez `index.html` dans votre navigateur.
